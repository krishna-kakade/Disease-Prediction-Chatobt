# Disease Prediction Chatbot

## Project Overview
The Disease Prediction Chatbot is an AI-based application designed to predict possible diseases based on user-reported symptoms.
It interacts with users through a chatbot interface and provides quick health insights using machine learning techniques.
The project aims to improve early disease awareness and assist users in making informed decisions.

## Objectives
- Predict potential diseases based on symptoms entered by the user
- Provide an interactive and user-friendly chatbot experience
- Apply machine learning concepts in a real-world healthcare use case
- Assist in early-stage health awareness (not a medical diagnosis)

## Technologies Used
- **Python**
- **Machine Learning**
- **Natural Language Processing (basic)**
- **Libraries:** NumPy, Pandas, Scikit-learn
- **Dataset:** Symptom–Disease dataset

## How It Works
1. User enters symptoms through the chatbot interface
2. Symptoms are processed and converted into a machine-readable format
3. A trained machine learning model predicts the most likely disease
4. The chatbot displays the predicted disease to the user

## Features
- Interactive chatbot-based input
- Fast disease prediction
- Simple and intuitive workflow
- Easily extendable with more diseases and symptoms
